It does not assert that those labels are a legal audit or that every upstream required notice is complete. Preserve attribution and original licence text; do not relabel all code MIT or imply endorsement. Some internal adaptations cite external guides that are not reproduced in full.

The supplied Office viewer assets were already part of the delivered Demo source. Their source/credit files are retained where present. Binary models/textures were copied and ASCII credential-pattern scanned, but were not re-rendered or fully inspected for embedded metadata, pixels or third-party redistribution rights. Independent public-release review is required.

This package removes credentials, personal contacts, production endpoints, actual identifier values, private client operational scripts/data-seed migrations, and top-level SQL row/backfill statements. Generic credential-vault and client-source-reader code is retained after sanitization. Anonymized labels and identifiers are source-copy adaptations, not fake customer evidence. Original source hashes and public export hashes are both recorded; exact omissions/redaction categories are inspectable.

Pattern scanning is not a proof that all possible secrets or confidential prose are absent. It checks credential prefixes, JWTs, private-key blocks, credential literal assignments, forbidden paths, JSON parseability, SQL top-level data removal and relative import file availability. It does not certify semantic equivalence, a build, runtime safety, app security or all media rights. No client data, native result or approval should be inferred from fixtures, registrations or the scripted Demo.
