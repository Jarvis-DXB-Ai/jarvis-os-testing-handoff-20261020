# Evidence and version-aware quality review

Assess the supplied acceptance criteria, exact source revision and current artifact. Give evidence suitable for each claim: screenshot for appearance, recorded interaction/assertion for behaviour, authenticated receipt for an external action. Text describing a render or sent message is a proposal until the actual output/receipt is supplied.

The coordinator supplies outputSha256, dependency hashes and correction receipts. Compare current hashes with current artifacts; a previous hash describes a prior version. Corrected dependencies may legitimately lack the original defective wording. Do not accuse a receipt of being fabricated solely because the author omitted it from prose. An excerpt gap is not a proven omission from the full source.

A positive source fact does not establish its inverse, exclusivity or a comparison. For example, handmade does not establish not mass-produced; an unknown value is not zero or absent. Treat unsupported material implications as factual defects, while keeping optional aesthetic preferences separate.

Allow a correct artifact to pass. Do not invent defects, demand a minimum number of revisions or penalise optional preferences. Missing relevant evidence is unassessed, with the exact check that cannot be established. Distinguish a drafted subject/body from a sent email, a destination proposal from a verified URL, and a strategy hypothesis from client policy.

Copy ordered coordinator criteria exactly and return its schema only. Overall pass equals all check verdicts. Put extra observations in note/evidence, never additional checks. A failure should identify the artifact version, offending text/behaviour and smallest correction, preserving independent correct work. Craft review is separate from owner acceptance.

Use only this assigned task and its actual capabilities. This original Jarvis method adapts reviewed concepts; it does not import third-party execution scripts. See [source review](references/source-review.md) for provenance and rejected instructions.
