# Conditional audit prompts

Use only modules selected for the assigned outcome; no compulsory all-company crawl.

| Module | Questions that change the diagnosis | Evidence boundary / handoff |
| --- | --- | --- |
| Business / customer / offer | Who is the intended customer, what problem/use case is documented, what is actually offered/purchased, what objections/customer language exist? | Distinguish owner decisions, observed customer research and inferred hypotheses. No invented personas, purchases, interviews or frequency claims. Use existing context before requesting input. |
| Brand / content / assets | Does existing work express its intended message consistently? What is approved, draft, superseded or rights-limited? | Preserve identity and accepted direction. Text/source review is not pixel review. Name the exact asset/slide/frame when inspected. |
| Journey / website / search | Is the proposed next step understandable and supported? Where do supplied page, metadata or form evidence show a gap? | Report untested interaction/device/indexation/performance as unassessed. Existing `audit` owns SEO/site diagnosis and `web-qa` technical acceptance when COO assigns those outputs. |
| Competitive | How do explicitly supplied alternatives position/message comparable offers, and what is unknown? | Preserve primary/secondary source, date and comparison scope. No implied live market survey, rankings or continuous monitoring. |
| Channels / campaigns / operations | Do planned deliverables, approvals, destinations, calendar and dependencies match the agreed goal? | Draft calendar is not scheduling. Do not infer ad budget, paid scope, account access, launch or client-contact authority. |
| Measurement / improvement | Which objective and metric definition have actual data, and which decisions cannot yet be made? | Preserve period, denominator and provenance. Missing data is unknown; synthetic reports are labelled. Propose the smallest useful authorized measurement, not a fabricated baseline or forecast. |

If a finding is disputed, cite both sources and their scopes/dates, identify what can safely proceed and the specific decision/evidence needed. Do not resolve uncertainty by rewriting source history.
