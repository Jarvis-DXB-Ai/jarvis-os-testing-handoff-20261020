# Office staging and scene quality contract

For an Office scene preserve the owner's interactive animated 3D direction and independent Jarvis implementation. Evaluate one connected workplace with distinct departments: room/desk clearance, reachable doors, realistic scale, circulation, furniture and planting, editable meshes/materials, readable labels and reduced decorative traffic.

The Dubai environment is spatial architecture around the Office, not a flat photo backdrop. Preserve location/time-linked daylight and restrained live signals. Decorative movement must not imply real task execution.

Use actual scene coordinates and floor-plan checks for overlap/door reachability; inspect the rendered view for composition and legibility. Report frame/performance evidence when measured, never infer it from geometry. New generated environments require a separate production route; a diffusion demo or scene photo does not implement editable runtime 3D. Treat the archive's render references as visual research, not licensed source code for reuse.

Use only this assigned task and its actual capabilities. This original Jarvis method adapts reviewed concepts; it does not import third-party execution scripts. See [source review](references/source-review.md) for provenance and rejected instructions.
