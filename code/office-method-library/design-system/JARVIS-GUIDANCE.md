# Jarvis adaptation: Reusable brand design rules

Inventory approved identity and applications. Specify semantic colour/type/spacing roles, layout grids, image treatment, variants and motion. Reuse the existing design system when one exists, rather than introducing a competing aesthetic. Make rules concrete enough for editable social graphics, ads and documents as well as UI. Check legibility, safe areas, text reflow, contrast and exports at actual size. Use verified font licences. A specification or code string is not an edited Figma/Canva/PPTX file without an execution receipt.

Upstream source and licence remain attached to the installed skill. This compact adapter is the active role context; source examples, install scripts and unselected references are not loaded or executed.
