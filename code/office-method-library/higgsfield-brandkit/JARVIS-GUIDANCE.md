# Jarvis adaptation: Brand application protocol

Extend an existing approved identity: official logo, colour roles, typography, imagery, spacing and application rules. Separate supplied source art from generated concepts and deterministic editable outputs. Preserve approvals and regenerate only requested derivatives. Prepare a manifest for requested social, signage or document formats with exact export and editable-file requirements. This optional method is not auto-routed; it does not authorize scripts, installation, rebranding, credits or output claims. Review on actual assets is required before brand approval.

Upstream source and licence remain attached to the installed skill. This compact adapter is the active role context; source examples, install scripts and unselected references are not loaded or executed.
