# Typography and information design
Research-reviewed synthesis · S07, S20, D05

A type system defines relationships and roles, not just font names. IBM illustrates responsive and script-sensitive type scales; NN/G connects scale and contrast to hierarchy. Use these principles while choosing type appropriate to the client's identity. [IBM](https://www.ibm.com/design/language/typography/type-scale/), [NN/G](https://www.nngroup.com/articles/good-visual-design/)

## Decisions to record

- Display, editorial heading, body, label, data and CTA roles.
- Family, source, licensed usage, weights, fallback and language support.
- Size, line-height, tracking, measure and responsive rules.
- Number/date/currency styles and permitted emphasis.
- Type over images, contrast pairs and minimum useful export size.

## Advanced craft

**Optical alignment:** large round letters, punctuation, logos and all-caps words may appear misaligned despite equal bounding boxes. Make small deliberate corrections after rendering. Do not distort the font or logo.

**Semantic contrast:** distinguish different jobs through size, weight, width, placement or style. If everything is oversized, the reader has no hierarchy.

**Controlled line breaks:** compose campaign headlines for rhythm without changing meaning. Recheck mobile and translations; a desktop manual break may create an orphan or misleading emphasis elsewhere.

**Tabular information:** align comparable values, name units and keep labels near their data. Use tabular numerals where the chosen font supports them and comparisons benefit. A report must remain legible before it becomes decorative.

**Density variants:** a campaign cover can be sparse; a menu, scope or FAQ needs efficient structure. Create both within one family instead of scaling one template down.

## Proof at actual size

Render the real output and inspect every slide/viewport. Check font substitution, clipped descenders, long words, widows, tiny labels, weak contrast and softened raster text. Keep digital copy selectable/editable where feasible.

Pairing fonts is an art-direction choice, not a rule that every brand needs a serif plus sans. Verify fonts from files or authoritative foundry information; never report an image-based guess as a confirmed family. Print and screen exports require separate checks.
