# Composition, rhythm and hierarchy
Research-reviewed synthesis · D05, D06, D10

NN/G describes hierarchy and visual principles as ways to direct attention and make relationships legible. IBM's 2x Grid shows how a repeatable underlying structure supports multiple layouts. Neither establishes one universal layout for all brands. [NN/G](https://www.nngroup.com/articles/good-visual-design/), [IBM](https://www.ibm.com/design/language/2x-grid/)

## Techniques

**Controlled asymmetry.** Establish a clear underlying grid; let a focal image or headline span it asymmetrically while aligning secondary information. Use when a campaign needs tension and character. Check the balance at phone size; asymmetry that leaves the information stranded is not refinement.

**Editorial pacing.** Alternate a hero composition, explanation, evidence and action. Change scale and density with the reader's task. Useful for carousels, proposals and long pages. Avoid repeating identical three-card sections regardless of content.

**Depth with a reading plane.** Layer images or mockups at varying scale and depth, but keep service names, prices and core text stable. Let a selected item resolve into a readable frontal view. Useful for a portfolio of deliverables; bad for dense scope tables.

**Visual grammar.** Repeat a small number of meaningful compositional behaviours: image edge alignment, caption anchor, numeral treatment, crop rhythm. Vary the subject and hierarchy within them. Consistency should remain visible when the logo is removed, without depending on identical layouts.

**Information-first diagrams.** Choose a timeline for sequence, matrix for comparison, map for location or relationship, and annotated image for physical detail. A decorative orbit cannot replace an explanation of causality.

## Construction and review

Sketch the reading order before styling. Use actual copy early; allocate whitespace around important information rather than using it to conceal missing content. Treat one strong focal point as a starting hypothesis, not a universal limit.

Check the silhouette at reduced scale, then read the actual details at intended size. Test long names, numbers and image alternatives. Inspect alignments optically as well as mathematically.

Do not assume a cropped screenshot demonstrates the original design's responsive behaviour. An attractive desktop composition needs its own mobile transformation.
