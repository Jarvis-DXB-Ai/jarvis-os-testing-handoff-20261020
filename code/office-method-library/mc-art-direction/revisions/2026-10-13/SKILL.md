# Applied design direction

Read the exact client brief and `/ABSOLUTE/TEST/OWNER/MC-STUDIOS/knowledge/design/README.md`. Inspect existing work and user-supplied references before designing. Preserve brand equity the user wants retained. Keep research methods separate from client-specific aesthetic decisions.

## Establish a defensible direction

Write the strategic problem and one art-direction thesis. Name three visible decisions that express it. Ground them in actual audience/content needs and inspected references, not adjectives such as premium, modern or sleek alone. When alternatives matter, compare directions on the same real content. Choose with a reason; do not combine everything.

## Apply the relevant craft

Load only the needed technique guides:
- `design/composition.md` — hierarchy, grids, asymmetry, rhythm and narrative.
- `design/typography.md` — type roles, optical craft, density and actual-size proofing.
- `design/motion.md` — continuity, choreography, controls and reduced-motion states.
- `design/avoid-generic-output.md` — diagnose weak defaults and repair the specific defect.

These are methods, not compulsory aesthetics. Advanced work can be restrained. Animation should clarify information or create a deliberate brand experience; it must not make scope, price or essential copy hard to read.

Specify foundations and rules as appropriate: type roles and verified font licences, palette/contrast pairs, spacing, image treatment, components, responsive variants, motion and export requirements. Explain how the system varies while staying recognisable.

## Prove it in applications

Create a representative finished output before expanding the system. Use real, useful copy and appropriate imagery. For a carousel inspect every slide; for a newsletter inspect email rendering; for a proposal inspect supporting sections, mobile, CTAs and motion controls. A beautiful cover does not establish quality of the whole deliverable.

Use `/ABSOLUTE/TEST/OWNER/MC-STUDIOS/knowledge/quality/DELIVERABLE-STANDARD.md`. Record pass/revise/not assessed with actual evidence. Do not invent test results, customer outcomes, approval or an objective 10/10 rating. Fix material defects before polishing decorative details.

Deliver the chosen rationale, working rules, finished examples and any unresolved production gaps. When knowledge maintenance is authorised, save transferable lessons centrally and client-specific decisions in that client's record. Never turn a one-client preference into a universal design ban.
