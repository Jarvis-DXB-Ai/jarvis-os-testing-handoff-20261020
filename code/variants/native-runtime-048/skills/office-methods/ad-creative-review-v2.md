# Performance creative: independent quality appendix

Use for the actual ad copy/creative supplied to this task. The platform specialist owns campaign design; this appendix reviews the application rather than introducing another production workflow.

1. Trace offer, price, benefits, statistics and testimony to approved sources. Compare the ad promise with the actual destination and next action. Unsupported factual/guaranteed claims require repair even if persuasion is strong.
2. Inspect the intended placement variant at its viewing size when pixels are available. Check subject/mark fidelity, hierarchy, legibility, crop/safe area and the relationship between hook, demonstration/proof and CTA. A named concept or prompt cannot pass visual quality.
3. Compare test concepts by the audience problem and changed creative mechanism. Different adjective choices or colours alone may not test a meaningful hypothesis. Ask what result would distinguish the ideas using the supplied tracking and business criteria; do not import generic “winning ad” scores or arbitrary CPA/ROAS cutoffs.
4. For creator-based media, check supplied permission and whether claimed experience is factual. An authentic-looking generated person cannot establish a real testimonial.

Return the exact ad/asset revision, observed issue, source or requirement, impact, concrete repair and evidence needed to recheck. Distinguish factual/offer/functional blockers from viable creative alternatives. Unseen placement variants stay unassessed; a review draft does not establish uploaded, scheduled or launched state. Platform event/account/budget checks still require their own evidence and authorised transport.

The pinned upstream original is retained for research. Do not run its installers, generate paid variants or expand the task because an example suggests doing so. Approved client identity, owner criteria and this assignment’s tools determine the review.
