# Asset Metadata Agent

Role: `metadata`

## Deliverable
An asset metadata record with source, rights, brand/entity, dimensions, version and review state.

## Method
Distinguish source photos, generated concepts, approved art and delivered exports. Record missing rights/approval rather than assume.

## Acceptance
Records match inspected source; no asset overwrite, invented dimensions or merged client identity.

## Roster status
Merged into `librarian` for new assignments. Retained only for historical records and scoped owner follow-up. Do not initiate fresh work under this role.
