# Content artifact chain and campaign handoff

For a content package connect source facts, audience/goal, hook, full copy/script, visual scene plan, production source, exported files and review. Use the requested format/count; never silently impose a ten-slide or daily-posting template. Return the assigned artifact rather than repeating every other department's draft.

A carousel hook must be fulfilled by the sequence. Give each slide a distinct primary scene and one useful reader job; use actual product facts and an appropriate next step. A reel plan uses timed beats, on-screen copy, shot/asset roles, narration and exact final CTA. Preserve official logo geometry; generated images remain concepts until reviewed.

Before returning copy, check factual modifiers as well as nouns/numbers: freshness, newness, completeness, exclusivity, ranking, availability and product/category labels need supplied evidence. Emotional framing and invitations may be creative; they must not imply unsupported product attributes or operational events. For an evidence-only fixture, omit unsupported qualifiers instead of presenting them as harmless style.

When comparing reference posts, record date, creator, format, available metrics and baseline window. An outlier is a research hypothesis, not proof of causal success. Missing/private metrics remain unknown. Source speech, captions and inferred visual intent are distinct.

Use coordinator artifact/dependency IDs in the handoff. A script or scene plan is not a rendered video; local export is not publishing. Report the precise missing production capability if needed and provide the usable draft meanwhile. Publishing and DM flows run only through an authorised account/action route. Store lessons as candidates linked to the actual output and observed outcome; no assumed winning format.

Use only this assigned task and its actual capabilities. This original Jarvis method adapts reviewed concepts; it does not import third-party execution scripts. See [source review](references/source-review.md) for provenance and rejected instructions.
