# Office v2 — web package

Production assets for the Jarvis OS Office page. Generated from Blender; do not edit the GLBs by hand —
regenerate with `blender/build/run.sh` + `export_web.py` (see "Regenerating").

## Files

| File | What it is |
|---|---|
| `office-environment.glb` | The tower floor: shell, 9 department rooms, arrival lobby, atrium (Max's suite, boardroom, lounge/bar), all furniture. No agents, no lights. |
| `office-agents.glb` | 66 seated agents. Each agent is one node named `agent:<id>` (e.g. `agent:head-of-social`) with its meshes as children. Poses are baked (no skeletons). |
| `manifest.json` | Rooms, zones, agents (role, department, manager flag, seat, facing, label anchor) and camera presets. |
| `CREDITS.txt` | Third-party asset credits (CC0 + CC-BY). CC-BY authors must stay credited (e.g. a credits/about page). |

Coordinates are three.js world space in metres (y-up). Blender (x, y, z) → three (x, z, −y). The footprint matches
the existing demo-tower formula (`demoBoundary`, 36.5 × 42 base radii), so it lines up with the current tower code.

## Loading (three.js r170)

```js
const loader = new GLTFLoader();
loader.setDRACOLoader(new DRACOLoader().setDecoderPath('/draco/'));   // ship the decoder locally
const env = await loader.loadAsync('/office/office-environment.glb');
const agents = await loader.loadAsync('/office/office-agents.glb');   // can load lazily after the environment
agents.scene.traverse(o => {
  if (!o.isMesh) return;
  for (const m of [].concat(o.material)) {
    if (/hair|brow|lash|high-poly/i.test(m.name)) { m.alphaTest = 0.5; m.transparent = false; m.side = THREE.DoubleSide; }
    else if (/^Human/.test(m.name)) { m.transparent = false; m.opacity = 1; }
  }
});
const node = agents.scene.getObjectByName('agent:head-of-social');   // highlight / click target
```

Requirements: `KHR_draco_mesh_compression`, `EXT_texture_webp`. Lighting is not baked: use an environment map
(RoomEnvironment) + soft key light, ACES/AgX tone mapping. The reference look is the renders in `previews/`.

## Mapping to the app

* `manifest.agents[].role` is the role title; `department` is the room code (CP, CE, CON, SOC, GD, BRN, WEB, ADS, OPS, MAX).
  Map these to the app's role/agent ids (office-role-skills / office-stack-plan) — the names changed in the restructure.
* `is_manager` marks the 9 department heads + Max (COO).
* `label_anchor` (agent and room) is where to project HTML status labels / task bubbles.
* `cameras` are suggested presets (overview, plan, Max's suite, lounge).

## Regenerating

```
cd blender/build
./run.sh 32 all                                  # build office, renders, live preview
blender -b ../office-v2/office-v2.blend -P export_web.py -- ../web-package
```
Cast (agents) is generated by `cast.py` (MPFB 2.0.18 + MakeHuman assets) into `blender/cast/cast.blend`.
