Eight recommendations for Jarvis
  1. Reliable evidence and QA — Adapt Evidence Collector’s reproducible requirement-based checks, strict output contracts and provenance validation into current QA. Reject automatic first-pass failures.
    Proposed acceptance check

    Replay the earlier benchmark defects: original/current hashes, missing evidence, unsupported completed actions and malformed QA. Correct artifacts may pass with zero reproducible defects.

    Proposed; no skill/runtime migration in this intake

  2. One content artifact chain — Research fact → audience/goal → copy → distinct scenes → timed production plan → verified export → QA → owner decision → measured outcome. Map ManyChat/Zernio/Canva routes only after verifying account and service scope.
    Proposed acceptance check

    One purchased-scope carousel/reel package has clear artifact versions and no paper render/post/DM success.

    Proposed

  3. A client-owned design contract — Use approved tokens/components/content/source roles plus observed extracted styles; topic-led composition and restrained motion. Existing client brand wins over generic style preferences.
    Proposed acceptance check

    Same approved page improves in screenshot, keyboard/mobile and reduced-motion checks without rebranding.

    Proposed

  4. Progressive retrieval and reference intake — Capture URLs/content with dates/rights/coverage; use small task-relevant packets; link client records to approved references without importing unrelated agency notes.
    Proposed acceptance check

    Source IDs, category counts and file hashes validate; a new reference is deduplicated and a changed source gets a new version.

    Library and intake procedure implemented here; Office runtime retrieval integration not changed

  5. A calibrated audience lab — Use small synthetic panels to find objections and confusion, label assumptions and compare with real customer feedback. Separate that output from market statistics.
    Proposed acceptance check

    A blinded held-out case produces useful specific criticisms; record false predictions and no simulated percentage is presented as real research.

    Pilot proposed; no simulation run

  6. Quota-aware resumable execution — Native terminal-state reconciliation, portable checkpoint, verified eligible model/tool route and preserved action receipts. Compare small-task allocation rather than expand to60agents.
    Proposed acceptance check

    Known quota interruption resumes correct work without duplicate writes or loss of context; fewer calls at equal independent quality.

    Proposed; no failover/runtime change

  7. Measured editing profiles — Per-client subtitle, cut, pace, music, safe-zone and export profile; editable source and rendered output both required.
    Proposed acceptance check

    One real clip has measured timing/readability and verified audio/video export.

    Proposed

  8. Editable office staging — Structured room/skyline scene, real scale and circulation, individual meshes/materials, reviewed lighting and camera.
    Proposed acceptance check

    No overlapping departments; walkable routes, reachable doors, readable labels and acceptable runtime performance.

    Design research only; no Office visual change
