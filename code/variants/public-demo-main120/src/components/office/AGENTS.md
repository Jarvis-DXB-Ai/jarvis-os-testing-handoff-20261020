# Office component identity rule

Before adding or changing a third-party app, model or protocol logo, read `../../../public/office-icons/README.md`. Register verified vendor artwork in `sources.json`; never invent a replacement symbol. Connection state must be shown separately from the logo's color and opacity. Run the icon verifier and visually check the rendered dock before handoff.

This supplements the root working agreement and preserves existing permissions and client scope.
