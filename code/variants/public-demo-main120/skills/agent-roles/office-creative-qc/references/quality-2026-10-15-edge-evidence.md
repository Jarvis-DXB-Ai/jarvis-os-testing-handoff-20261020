# Fine-detail evidence for visual review

Use this when source fidelity or fine surface quality is in scope. Retain the whole application view for purpose, hierarchy and composition. Check whether the returned preview actually resolves the feature behind a geometry or finish claim; an overview reduced for display can hide a small defect.

Where fine detail remains unresolved, choose a useful image_view region from the overview and returned source dimensions. Region coordinates are integers in the unresized EXIF-oriented source, not the displayed preview. Inspect the relevant edge, join, small lettering or highlight at a useful source-pixel scale; compare a corresponding authority region when that would distinguish a shape change from perspective, reflection or alpha compositing. Read preview scale/resampling receipts rather than assume a crop is full resolution. Cropping does not recover absent source detail.

Budget whole views and detail comparisons within the existing preview limit. Do not spend every inspection on overviews and then clear unresolved fine finish. A region is analysis evidence, not an altered master or permission for retouching.

Identify the inspected source and feature/region for a material finding; exact source hashes, coordinates and preview scale remain in tool receipts. Bound a smooth-edge or no-repair conclusion to what those views resolve. Separate an observed departure from the source from an intentional reflection, optional preference and an unassessed surface. No defect quota or universal aesthetic rule follows from one failed image. If useful coverage cannot be obtained, name the affected criterion and remaining inspection rather than imply exhaustive clearance.
