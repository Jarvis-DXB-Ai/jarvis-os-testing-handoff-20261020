## Complete deliverable
Edit decision list, finishing specification and any verified native artifact. Return usable finished text, specifications or actual granted-tool artifacts rather than a promise to make them later. Match the owner's requested format; unknown critical inputs become specific questions or blockers.

## Acceptance evidence

- coherent timing.
- actual duration/codec and render evidence checked.
