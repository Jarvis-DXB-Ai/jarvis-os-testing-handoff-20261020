# Brand identity, visual systems and presentations

Use the locked brand revision and official source marks. New identity exploration is a distinct authorised task; a style reference or generic vendor brand guide cannot replace client identity. State the communication problem and one art-direction thesis, then explain concrete type, composition, image and motion decisions using actual audience/content needs.

Specify type roles and licensing, brand/semantic colours, grid, spacing, hierarchy, image treatment, variants and motion controls. Demonstrate rules in useful real applications: social, deck, email or website as scoped. Distinguish editable source, visual mockup and rendered export. A list of hex codes alone is not a working design system. Check logo proportions, crops, terminology, image source roles and readable intended sizes. Let motion explain hierarchy or state and retain usable reduced-motion behavior.

For decks, create a decision-oriented narrative before decoration. Give each slide one job, a supported headline, actual evidence, a visual plan and a transition to the next idea. Preserve the owner's selected MC template when supplied. Brand-guideline decks need examples showing how rules apply and fail; proposals need service quantities and prices that agree. Avoid repeated filler slides or one image reused throughout the deck.

Critique the complete representative application: purpose, hierarchy, typography, alignment, contrast, reference fidelity, mobile/export crop and interaction where applicable. Ask for the actual rendered pages/screens if the run cannot inspect them; mark visual claims unassessed until evidence exists. Write concrete repair instructions with affected element/page and why the change helps. Feedback becomes a candidate lesson with client/department scope, never an automatic global aesthetic ban.

## System and critique calibration — fictional example

An approved mark must remain untouched while adapting a proposal template. Define text roles such as display/body/data label, semantic colour roles and spacing relationships; demonstrate them on an actual service slide and a mobile contact section. A token called “blue-1” with no intended use is less useful than a documented brand-primary role with contrast/application evidence.

A useful critique names the affected slide or element, intended viewing size, observed competing hierarchy and a concrete change. “Make it more premium” lacks a review target. “The body and title have equal emphasis; reduce body weight and restore the approved title role” can be rechecked. Do not pretend this example establishes contrast or rendering for unseen client pages.
