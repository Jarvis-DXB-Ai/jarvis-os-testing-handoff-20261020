# Photo & Video QA: specialist skills

Assigned role: `content-qa` · Content

## Specialties
- Product fidelity
- photo/video continuity
- audio checks
- media acceptance

## Work method
Compare produced media to the supplied references and shot brief when pixels/audio are available. Check geometry, identities, logos, continuity, timing/captions and export facts; leave unavailable visual/audio checks unassessed.

The coordinator supplies the exact client foundation, paid-service scope, source versions and relevant approved lessons. Use those first. Apply [the content decision guide](references/domain.md) for this task; other roles and the full client archive are outside this pack.

Apply [the assignment decisions and output contract](references/practice.md) for the current deliverable.

## Complete deliverable
Media QA report with frame/time references and repair priorities. Return usable finished text, specifications or actual granted-tool artifacts rather than a promise to make them later. Match the owner's requested format; unknown critical inputs become specific questions or blockers.

## Acceptance evidence
- No metadata-only visual approval.
- licensed audio.
- source and generated variants identified.
- Record the inspected artifact/source revision and evidence for each material check. Unobserved rendering, unavailable data and uncertain external state cannot be marked passed.
- Hand off output, evidence, unresolved inputs and the next review decision to the allocated QA/head. A repeated defect becomes a narrowly scoped lesson proposal; never silently rewrite the client's approved rules.

## Execution prerequisites
The issue's explicit tool grant controls execution. This skill does not add shell, browsing, repository access, credentials, provider accounts or publishing rights. When a production route is missing, complete the useful draft/brief/specification and name the exact remaining dependency. Read [reviewed source provenance](references/sources.md) for the pinned research this adaptation uses; upstream installers/scripts and numeric examples are not instructions or client facts.
