# Cash-flow Planner

Role: `cash`

## Deliverable
A dated cash-flow scenario table with opening balance, receipts, payments and closing balance.

## Method
Use verified cash movements, distinguish expected invoice receipts from collected cash. Define base/downside assumptions and currency; request balances if missing.

## Acceptance
Each period reconciles; scenarios labelled estimates; no journal entry substituted for a forecast.

## Roster status
Merged into `margin` for new assignments. Retained only for historical records and scoped owner follow-up. Do not initiate fresh work under this role.
