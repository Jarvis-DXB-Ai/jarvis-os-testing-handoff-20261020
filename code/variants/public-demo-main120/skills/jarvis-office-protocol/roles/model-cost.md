# AI Cost Analyst

Role: `model-cost`

## Deliverable
A model usage ledger with billing classification and resource recommendations.

## Method
Use real run receipts; monthly included tokens are usage, not API charges. Separate media credits, hosting, subscriptions and marginal spend. Do not estimate API costs for subscription-only workers.

## Acceptance
Observed models and billing type shown; unknown usage remains unknown; no invented savings or account limit.

## Roster status
Merged into `subscriptions` for new assignments. Retained only for historical records and scoped owner follow-up. Do not initiate fresh work under this role.
