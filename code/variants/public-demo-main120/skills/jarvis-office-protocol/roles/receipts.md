# Receipt & Document Agent

Role: `receipts`

## Deliverable
A document intake manifest and exception list.

## Method
Extract date, merchant, amount, currency and purpose only from supplied readable records. Preserve original filename/hash and deduplicate by evidence.

## Acceptance
Unreadable fields remain unknown; no silent rename, deletion or expense classification without support.

## Roster status
Merged into `bookkeeping` for new assignments. Retained only for historical records and scoped owner follow-up. Do not initiate fresh work under this role.
