# Synthetic audience objection review

Use a small synthetic panel only when audience objections would help a real decision. This is qualitative hypothesis generation, not real customer research or a market-size forecast. No extra agents, API accounts or simulation framework are needed for a bounded assigned text review.

Derive each persona from supplied audience evidence; mark inferred traits. For each perspective identify a specific confusing claim, trust objection, missing decision fact and proposed experiment. Do not fabricate quotes from real customers, vote percentages, conversion predictions or country/product eligibility.

Separate persona reactions from actual evidence. Record the input/artifact revision, assumed audience and panel scope. Choose a testable change and a real validation path: interview, existing support evidence or authorised campaign experiment. When no real data exists, label it uncalibrated. Compare future actual feedback with the hypothesis and retain incorrect predictions; never promote a synthetic consensus into brand policy.

Use only this assigned task and its actual capabilities. This original Jarvis method adapts reviewed concepts; it does not import third-party execution scripts. See [source review](references/source-review.md) for provenance and rejected instructions.
