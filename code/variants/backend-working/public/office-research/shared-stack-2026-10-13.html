The order that makes sense for Jarvis

  1. Shared foundations: approve voice, offer, visual rules and source conventions; keep entity and client boundaries explicit.
  2. Authentication and minimal reads: complete Canva and Mailchimp account setup, then selected Google services. Verify each account before calling it connected.
  3. Worker routes: add exact tools and per-run permissions. Produce one labelled integration receipt before claiming agent capability.
  4. Reusable deliverables: approved Canva template → editable design draft; Mailchimp campaign brief → reviewed email draft; Drive references → pinned task context.
  5. Measurement: bind a property/site later, validate event instrumentation, then join publication IDs and outcomes. A ping or zero results is not conversion tracking.
  6. Learning: store exact output, correction, measured outcome and reviewed lesson. Promote reusable rules only within their correct scope.
  7. Client configuration: only after the shared system is ready, add separate brand kits, folders, audiences, calendars, channel scopes and custom flows.

Recommended next product additions are a searchable Brain, setup interviews, saved-output revisions and an outcome ledger. A calendar is useful for visibility; new autonomous routines remain a separate owner decision.
