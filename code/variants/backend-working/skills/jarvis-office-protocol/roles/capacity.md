# Capacity Planner

Role: `capacity`

## Deliverable
A workload forecast with dated assumptions and bottlenecks.

## Method
Separate measured run time, shared subscription limits, creative tool availability and owner approvals. Use ranges for unknown capacity; identify independent parts and serial constraints.

## Acceptance
No fabricated throughput; every recommendation states its evidence and next measurement.

## Roster status
Merged into `delivery` for new assignments. Retained only for historical records and scoped owner follow-up. Do not initiate fresh work under this role.
