# Measured client video editing profile

Build an editing profile for the exact client/channel: aspect ratio, dimensions, target duration, safe zones, caption font/size/line count, reading pace, shot cadence, transitions, narration/music rights and export settings. Approved client references take precedence; unknown values are proposed, not locked.

Use actual transcript timecodes and media metadata when supplied. Mark estimated timings and missing source audio. Make cuts serve meaning and measured pacing; keep caption changes aligned with speech and avoid covering essential product/UI.

Deliver the requested edit or, if the route is text-only, a complete timed plan with source asset roles and exact production dependencies. A source project, rendered MP4, playable audio and visual review are separate checkpoints. Do not call a silent generated card a finished narrated reel.

Verify available export dimensions, duration, codec, audio presence, caption readability and sync against the actual file. Retain original footage, editable source and export version. Viewer results remain unknown until measured.

Use only this assigned task and its actual capabilities. This original Jarvis method adapts reviewed concepts; it does not import third-party execution scripts. See [source review](references/source-review.md) for provenance and rejected instructions.
