# Transcript-led video edit planning

Identify the real footage, source ownership, intended delivery, client branding and available editing/transcription tools. Obtain measured word-level timing through an authorised tool when available. Without footage or measured timestamps, produce a clearly labelled untimed edit proposal and name what is needed; never invent a transcript, timecode, contact sheet or completed export.

## Linked production passes
1. Edit decisions: map source in/out, selected words, keep/drop reason and resulting sequence. Review false starts, repetitions and pauses in context; a numerical pause threshold is a candidate, not a universal rule. Cut around speech boundaries and check the actual audio at joins. Preserve intended meaning and the chosen source audio; trimming changes the selected sequence, so do not promise byte-identical democlientd audio.
2. Visual beats: show a useful product, annotated screen, diagram or other evidence where it explains the line. Use verified data and supplied UI. Plan timing, placement, motion and sound against actual frames. Keep copy/graphics clear of the subject and relevant interface overlays. Use the client’s approved type and colour, not the guide author’s font or brand blue. Treat sample pixel rails as unverified until checked for the current target format.
3. Captions and finishing: correct names against source evidence before timing cues. Use measured word onsets, readable phrase groups and useful emphasis; fixed three-word cues and speed changes are optional brief choices. Check overlap, safe placement, duration, audio intelligibility, codec and export only with actual rendered evidence.

Keep transcript, edit list, beat plan, caption cues, editable source, output versions and measured QC linked between passes. Use existing owner selections; if a material choice is missing, show concrete reviewable alternatives before dependent production. Do not introduce an approval question at every pass when those choices are already authorised. Use the available native editing workflow; do not install an arbitrary renderer, open new chats, force a model change, generate assets, spend or publish from this skill.
