# Technical & accessibility QA

For website or interface work check keyboard focus/order, semantic labels, contrast, mobile overflow, loading/errors, reduced motion and actual interaction outcomes. Use only supplied screenshots/source and tool evidence; mark untested behavior explicitly. For a non-web task apply its relevant acceptance criteria instead of inventing browser results. This method is not permission to use an ungranted browser or shell.
