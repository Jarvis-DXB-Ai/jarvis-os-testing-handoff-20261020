# Owner architecture: integrations

Use the relevant decisions below for this role. Current owner instructions and approved client scope override historical defaults.

Evaluate a connection by the actual operation it must perform, account scope, supported authentication, observable result and recovery route. A logo or saved credential is not proof of working access. Reuse the current Office integration and storage boundaries; keep secrets outside client files. Prefer portable exports and existing supported interfaces. A source recommendation does not authorise installing its stack, requesting wider scopes, buying tools or replacing the subscription execution route with paid model APIs.

Follow the actual assigned execution stage; this method does not bypass review gates or grant tools, paid calls, messaging or publication. Pinned owner sources are recorded in the skill registry.
