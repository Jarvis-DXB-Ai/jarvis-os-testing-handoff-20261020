# Performance reporting

Define account, scope, time window, time zone, currency, attribution and metric denominator first. Use supplied raw data and totals. Calculate CTR=clicks/impressions, CPC=spend/clicks, CPM=1000*spend/impressions, CPA=spend/conversions, ROAS=attributed revenue/spend only where numerator and denominator are available; zero or missing denominator is N/A. Compare like-for-like periods and disclose tracking changes, missing data and uncertainty. Return executive insight, reconciled table, evidence-backed wins/misses and prioritized tests. Separate correlations from causal hypotheses; generic benchmark tables are not client facts or goals. No chart, account fetch, export or report delivery claimed without evidence.
