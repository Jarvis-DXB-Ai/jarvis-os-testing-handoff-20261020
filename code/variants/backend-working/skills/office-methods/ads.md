# Jarvis adaptation: Paid campaign planning

Start from offer, customer, objective, available budget and measurement event. Define the funnel, landing-page match, creative concepts, audience hypothesis, naming and review manifest. Select the smallest meaningful experiment with metric and decision rule; avoid imposing a minimum number of tests. Distinguish platform recommendations from verified account settings. Interpret supplied spend/conversion data with explicit time zone, currency and attribution. No account access assumed, no fixed performance benchmark copied from upstream, no budget change or launch without owner approval.

Upstream source and licence remain attached to the installed skill. This compact adapter is the active role context; source examples, install scripts and unselected references are not loaded or executed.
